ROLE CONTRACTS / SELECT TO EXPAND

Current code and proposed network behavior are separated.

01MinerFetch source; return field delta＋

Signed POST /v1/compare receives an exact prior publication, change publication, and TED reference. The miner independently queries the live TED API, confirms that the current notice explicitly references the prior one, and returns changed JSON paths, typed values, source hashes, and source-value evidence. It rejects oversized, malformed, unsupported, stale, incomplete, or unlinked requests. The service verifies Bittensor hotkey signatures and checks that the caller holds a validator permit on the configured test subnet.

02ValidatorIndependently retrieve and score＋

For each actual TED pair, the validator independently fetches the source records, derives the target delta, validates miner signature, schema, task identity, publication linkage, and record hashes, then checks exact changed paths, values, and evidence. It retains component results per UID. No LLM judge is needed for this exact structured task. A future unstructured notice task requires a separately labeled real corpus before it can affect rewards.

03WeightsNormalize repeated evaluation＋

Aggregate bounded recent task scores per active miner, preserve failed-task zeros, normalize nonnegative scores to relative weights, and submit through the current Bittensor SDK's test-network SetWeights intent. Chain consensus and emissions remain Bittensor responsibilities; no chain transaction is claimed by this interface.
